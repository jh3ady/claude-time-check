# Agent instructions

A Claude Code plugin built on function hooks (early access API).

## Commands

- `claude plugin test .`: run the tests in `hooks/*.test.ts`.
- `claude plugin validate .`: check the manifest and the hooks module.
- `claude --plugin-dir .`: load the plugin in a session with hot reloading.

## Map

- `hooks/register.tsx`: the hooks (prompt gating, panes, `/time-check` command).
- `hooks/schedule.ts`: pure scheduling logic, covered by `hooks/schedule.test.ts`.
- `types/index.d.ts`: the `$.state` contract.
- `.claude-plugin/types/` is generated by Claude Code on load and is not committed.

## Conventions

- Test-driven: change `schedule.test.ts` first for any scheduling rule.
- Commits: gitmoji plus Conventional Commits, for example `✨ feat(schedule): add per-day windows`.
- Bump `version` in `.claude-plugin/plugin.json` for every release.
